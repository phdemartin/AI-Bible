# 📖 AI Bible — Logos & Lumière (Studio d'Étude Biblique & Exégétique)

**AI Bible — Logos & Lumière** est un studio d'étude biblique multi-colonnes (pour **1 ou 2 écrans**) conçu pour l'étude exégétique approfondie et la préparation de prédications en **Français 🇫🇷**, **Espagnol 🇪🇸** et **Anglais 🇬🇧**.

## ✨ Fonctionnalités principales

- **📐 Mises en page modulables (1 ou 2 écrans)** :
  - Choix visuel au démarrage (ou à tout moment via le bouton **« 📐 Mise en page »**) : *2 Colonnes*, *3 Fenêtres Mixtes (1 Écran)*, *4 Fenêtres Mixtes*, *3 Colonnes Côte à Côte* ou *4 Colonnes Studio (Double Écran)*.
  - Chacune des 4 fenêtres est **100 % interchangeable** : 📖 Bible, 📚 Commentaires & TSK, 🏛️ Dictionnaire Grec/Hébreu Strong, 🤖 IA Gemini & Sources, ou 📝 Notes Personnelles.
- **📥 Téléchargeur intégré de Modules SWORD (`~/.sword`)** :
  - Accès direct aux 15 dépôts officiels (**CrossWire**, **eBible.org**, **STEP Bible**, **Xiphos**, **Bible.org**, **Lockman**, **IBT**, etc.).
  - Filtrage par cases à cocher de toutes les langues (🇫🇷 Français, 🇪🇸 Español, 🇬🇧 English, 🏛️ Grec Ancien, 🕎 Hébreu, etc.).
  - **100 % compatible et partagé avec BibleTime / Xiphos** via le dossier standard `~/.sword`.
- **🏛️ Grec & Hébreu (Codes Strong & Morphologie)** :
  - Clic direct sur n'importe quel mot d'une Bible pour afficher son étude lexicale Grecque ou Hébraïque et le surligner dans toutes les Bibles ouvertes.
- **📝 Fiches de Notes Personnelles indexées par verset** :
  - Sélectionnez n'importe quel extrait d'une réponse IA Gemini, d'un commentaire ou d'un dictionnaire → *Clic droit → « 📝 Ajouter la sélection à la note de [Verset] »*.
  - Export en 1 clic pour traitement de texte (**LibreOffice Writer / Microsoft Word**, texte noir sur fond blanc sans cadre gris).
- **🤖 Assistant Exégétique IA Gemini & Dossier de Sources Locales** :
  - Sélecteur de langue de réponse (`🇫🇷 Français`, `🇪🇸 Español`, `🇬🇧 English`) et traduction en 1 clic pour prêcher dans plusieurs langues.
  - Dictée vocale hors-ligne intégrée (`🎤 Dicter`).

## 📦 Téléchargement & Installation (Windows & Linux)

Rendez-vous dans la section **[Releases](../../releases)** de ce dépôt GitHub pour télécharger la dernière version :

1. **🪟 Windows 10 / 11 (64 bits)** — `AI_Bible-1.0.0-Windows-x64.zip` :
   - Décompressez l'archive `.zip` et double-cliquez sur **`AI_Bible.exe`**.
   - Cliquez sur **« 📥 Télécharger / Gérer des Modules »** pour choisir vos langues et télécharger vos Bibles gratuitement.
2. **🐧 Linux (Toutes distributions)** — `AI_Bible-1.0.0-x86_64.AppImage` :
   - Rendez le fichier exécutable (`chmod +x AI_Bible-1.0.0-x86_64.AppImage`) et double-cliquez dessus.
3. **🐧 Ubuntu / Debian / Linux Mint** — `ai-bible_1.0.0_amd64.deb` :
   - Installez via `sudo apt install ./ai-bible_1.0.0_amd64.deb`.
